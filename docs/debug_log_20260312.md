## Bug 1: `MODEL_PATH` 未定义

**报错**
```
NameError: name 'MODEL_PATH' is not defined
```

**位置**
`omni_vla/src/openpi/models_pytorch/vlm_with_spatial.py:174`

**原因**
`VLMWithSpatialActionExpertModel.__init__` 有 `vlm_pretrained_path` 参数，但代码内部误用了未定义的全局变量 `MODEL_PATH`。

**修复**
```python
# 修改前
state_dict = load_file(MODEL_PATH, device="cpu")

# 修改后
state_dict = load_file(vlm_pretrained_path, device="cpu")
```

## Bug 4: FSDP 混合 `requires_grad` 报错

**报错**
```
ValueError: Must flatten tensors with uniform `requires_grad` when `use_orig_params=False`
```

**位置**
`rlinf/hybrid_engines/fsdp/strategy/fsdp.py:80`，FSDP 初始化时

**原因**
模型部分参数被冻结（`requires_grad=False`），部分可训练（`requires_grad=True`），但 FSDP 配置 `use_orig_params=False` 要求同一 flat param 组内所有参数的 `requires_grad` 一致。

**修复**
在 `examples/embodiment/config/libero_spatial_ppo_omni_vla_quickstart.yaml` 的 `fsdp_config` 中添加：
```yaml
fsdp_config:
  use_orig_params: True   # 新增
```

## Bug 5: `GemmaModel` 没有 `.model` 属性

**报错**
```

```

**位置**
`rlinf/models/embodiment/omni_vla/omni_vla_action_model.py:604`，以及

**修复1 - 权重 key 映射**（`vlm_with_spatial.py`）：

```python
# 修改前
return "language_model.model." + key[len("model.language_model."):]

# 修改后
return "language_model." + key[len("model.language_model."):]
```

**修复2 - 运行时属性访问**（`vlm_with_spatial.py` 多处 + `omni_vla_action_model.py`）：
```python
# 修改前（示例）
```

涉及文件：

## Bug 6: `rollout_size` 不能被 `batch_size_per_rank` 整除

**报错**
```
AssertionError: 384 is not divisible by 256
```

**位置**
`rlinf/workers/actor/fsdp_actor_worker.py:1318`

**原因**
`rollout_size = total_num_envs(8) × rollout_epoch(2) × num_action_chunks = 384`，
`batch_size_per_rank = global_batch_size(512) // world_size(2) = 256`，
`384 % 256 ≠ 0`。

**修复**
将 `global_batch_size` 从 512 改为 384，使 `batch_size_per_rank = 192`，`384 % 192 == 0`：
```yaml
# examples/embodiment/config/libero_spatial_ppo_omni_vla_quickstart.yaml
actor:
  global_batch_size: 384  # 原来是 512
```

## Bug 7: CUDA OOM（显存不足）

**报错**
```
torch.OutOfMemoryError: CUDA out of memory. Tried to allocate 196.00 MiB.
GPU 0 has a total capacity of 79.25 GiB of which 157.81 MiB is free.
```

**原因**
- `micro_batch_size=16` 导致每次前向激活量过大
- Rollout Worker 与 Actor 部署在同一 GPU，显存中同时存在两份模型权重
- `gradient_checkpointing=False`，所有激活值保留在显存中

**修复**
将 `micro_batch_size` 从 16 降至 8：
```yaml
actor:
  micro_batch_size: 8  # 原来是 16
```

## Bug 8: attention mask dtype 与 query dtype 不匹配

**报错**
```
RuntimeError: invalid dtype for bias - should match query's dtype
```

**位置**
`omni_vla/src/openpi/models_pytorch/vlm_with_spatial.py:328`，在 `spatial_expert.forward()` 内部的 SDPA 调用

**原因**
`_prepare_attention_masks_4d` 生成的 mask 是 **float32**（Python float 字面量默认 float32）。`reasoning_expert` 使用项目自定义的 `transformers_replace` 实现，对 mask dtype 宽松；而 `spatial_expert` / `action_expert` 使用 HF 官方 `GemmaForCausalLM`，SDPA 严格要求 mask dtype 与 query dtype（bfloat16）一致。

**修复**
在调用 `spatial_expert` 和 `action_expert` 前，将 attention mask 转换为对应模型参数的 dtype：
```python
# vlm_with_spatial.py - spatial_expert 调用处
spatial_dtype = next(self.spatial_expert.parameters()).dtype
spatial_attention_mask = attention_mask.to(dtype=spatial_dtype) if attention_mask is not None else None
middle_output = self.spatial_expert.forward(
    inputs_embeds=inputs_embeds[1],
    attention_mask=spatial_attention_mask,
    ...
)

# vlm_with_spatial.py - action_expert 调用处
action_dtype = next(self.action_expert.parameters()).dtype
action_attention_mask = attention_mask.to(dtype=action_dtype) if attention_mask is not None else None
suffix_output = self.action_expert.forward(
    inputs_embeds=inputs_embeds[2],
    attention_mask=action_attention_mask,
    ...
)
```
